# Objective

# Completed Modules

## 1. Authentication & Authorization

- JWT-based authentication
- User registration
- Secure login endpoint
- Bearer token authorization
- Current user profile API
- Password encryption using Spring Security

**Verified APIs**

- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/users/me`

---

## 2. Customer Management

Implemented complete customer profile lifecycle.

### Features

- Create customer profile
- Retrieve own profile
- Update profile
- Validation using Jakarta Validation

**Verified APIs**

- `POST /api/customers`
- `GET /api/customers/me`

---

## 3. KYC Module

Built customer verification workflow.

### Workflow

`NOT_STARTED → PENDING`

### Features

- Create KYC record
- Retrieve own KYC
- Submit verification request

**Verified APIs**

- `POST /api/kyc`
- `GET /api/kyc/me`
- `POST /api/kyc/me/submit`

## 4. Digital Asset Module

Implemented collateral declaration system.

### Features

- Declare assets
- Retrieve asset by ID
- Retrieve authenticated user's assets

### Example Asset

- Vehicle
- Hyundai i20 Sportz
- Declared value: ₹850,000

**Verified APIs**

- `POST /api/v1/assets`
- `GET /api/v1/assets/me`
- `GET /api/v1/assets/{assetId}`

## 5. Borrowing Request Module

Implemented loan application workflow.

### Features

- Create borrowing request
- View borrower requests
- Get request by ID
- Submit borrowing request

### Workflow

`DRAFT → SUBMITTED`

**Verified APIs**

- `POST /api/v1/borrowing/requests`
- `GET /api/v1/borrowing/requests/me`
- `GET /api/v1/borrowing/requests/{id}`
- `POST /api/v1/borrowing/requests/{id}/submit`

## 6. Lending Partner Module

Implemented institutional lender registration.

### Features
